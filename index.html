LIVE WHILE OPEN
What this monitors

Metric Atlas checks Metric's public pool metadata every minute while this page is open. It records observed provider issues, pause states, and removals from the public pool listing. This is not a 24/7 alert service or a direct price-feed freshness probe. An unknown signal is never treated as healthy.

HOW TO READ THIS

Evidence first, no invented certainty.

“Provider issue” reflects the API's reported priceProviderStatus. “Paused” reflects a positive pauseLevel or a pool_paused status when the pause level is unavailable. “Removed” uses Metric's separate excluded-pool response. A condition is marked resolved only after a later successful refresh no longer reports it. Verify consequential decisions with Metric and the chain.

COVERAGE & LIMITS

Observed, never assumed.

The live API check refreshes every 60 seconds while this page is open. Live observations exist only in this tab; the independent background archive can be delayed, so check its separate timestamp above. Archived metadata changes and sampled quote responses are observations, not verified causes. No quote guarantees a swap will execute. Missing pools are unconfirmed rather than called removed. Daily event files preserve older archived observations.
